# رمزیار · Ramzyar

**پایان گشتن دنبال کد یک‌بارمصرف در اعلان‌ها.** رمزیار یک اپ اندرویدی کوچک و کاملاً آفلاین است: پیامک رمز را می‌خواند، کد را از آن بیرون می‌کشد، در کلیپ‌بورد کپی می‌کند و در یک نوار باریک روی همان برنامه‌ای که در آن هستید نشان می‌دهد.

## مسئله چیست؟

در اندروید، رمز یک‌بارمصرف یک پیامک معمولی است و هر راه‌حل سیستمی یکی از این دو مشکل را دارد:

- **پیشنهاد Autofill** فقط در اپ‌هایی کار می‌کند که پشتیبانی کرده‌اند و فقط روی فیلد فعال.
- **پاپ‌آپ اعلان** دقیقاً وقتی می‌خواهید کد را ببینید زیر کیبورد می‌رود.
- **کپی دستی** یعنی رفتن به اپ پیامک، پیدا کردن پیام و انتخاب دستی ارقام.
- پیامک‌های فارسی بدتر هم هستند: کد اغلب با **ارقام فارسی** (`۴۸۲۹۱۳`) می‌آید و متن هر بانک متفاوت است (رمز پویا، کد تایید، کد فعال‌سازی…)، پس پارسرهای سادهٔ «اولین عدد ۶ رقمی» عدد اشتباه برمی‌دارند.

## ویژگی‌ها

- **استخراج کد روی خود دستگاه** — بدون سرور، بدون مدل، بدون حساب کاربری.
- **نوار شناور باریک** به‌جای پاپ‌آپ تمام‌صفحه؛ قابل جابه‌جایی و موقعیتش ذخیره می‌شود.
- **انتخاب هوشمند کد** — تبدیل ارقام فارسی/عربی به لاتین، پیدا کردن همهٔ دنباله‌های عددی و انتخاب نزدیک‌ترین عدد به *آخرین* کلیدواژهٔ رمز؛ مثلاً از `رمز قبلی 9999 باطل شد. رمز جدید شما 12345` عدد `12345` بیرون می‌آید.
- **کپی خودکار** هنگام دریافت، و کپی دوباره با ضربه روی نوار.
- **کلیدواژه‌های سفارشی** — عبارت بانک یا سرویس خودتان را اضافه کنید (`شناسه بازیابی`، `کد ورود`، …).
- **لیست سیاه کلمات و شماره‌ها + لیست سفید فرستنده‌ها** — پیامک تبلیغاتی و فرستندهٔ ناشناس پردازش نمی‌شود.
- **بستن خودکار اعلان پیامک** حاوی رمز (با دسترسی مدیریت اعلان‌ها) تا سینی اعلان پر از رمزهای مرده نشود.
- **تاریخچهٔ ۳۰ رمز آخر** همراه فرستنده و زمان.
- **تایمر بستن خودکار** (۱۰ تا ۶۰۰ ثانیه، پیش‌فرض ۱۱۰) به‌صورت یک خط پیشرفت نازک.
- **لرزش** هنگام دریافت، رابط راست‌چین با فونت وزیرمتن، تم روشن و تیره.

## چطور کار می‌کند؟

```
پیامک می‌رسد
   │
   ▼
SmsReceiver (BroadcastReceiver + goAsync)
   │  • اپ فعال است؟
   │  • فرستنده در لیست سیاه است؟ / لیست سفید فعال است و فرستنده مجاز نیست؟
   ▼
CodeExtractor.extractSmartWithLabel(message, customKeywords, blacklistWords)
   │  • تبدیل ۰-۹ و ٠-٩ به 0-9
   │  • یافتن دنباله‌های ۴ تا ۱۰ رقمی
   │  • کلیدواژه‌ها = لیست پیش‌فرض + کلیدواژه‌های کاربر
   │  • لنگر = آخرین کلیدواژه؛ نزدیک‌ترین عدد انتخاب می‌شود (عدد بعد از لنگر اولویت دارد)
   ▼
   ├─ کپی در کلیپ‌بورد (اختیاری)
   ├─ لرزش (اختیاری)
   ├─ افزودن به تاریخچه (حداکثر ۳۰)
   ├─ بستن اعلان پیامک مربوطه (اختیاری)
   └─ اجرای SmsOverlayService ──▶ نوار شناور + شمارش معکوس ← ضربه = کپی / کشیدن / بستن
```

هیچ سرویس پس‌زمینهٔ دائمی و هیچ کار زمان‌بندی‌شده‌ای وجود ندارد.

## حریم خصوصی

- اپ **مجوز `INTERNET` ندارد** — در `app/src/main/AndroidManifest.xml` قابل بررسی است؛ یعنی فنی امکان ارسال پیامک به جایی را ندارد.
- متن پیامک فقط در حافظه پردازش می‌شود؛ تنها کد استخراج‌شده، برچسب آن و فرستنده به‌صورت محلی (DataStore) ذخیره می‌شود، حداکثر ۳۰ مورد و قابل پاک‌کردن از داخل اپ.
- بدون آنالیتیکس، بدون کرش‌ریپورت، بدون تبلیغات و بدون کتابخانهٔ شبکه.

## پیش‌نیازها

- اندروید ۷.۰ (API 24) یا بالاتر، دستگاه **arm64-v8a** (نسخهٔ انتشاری فقط ARM64 است).
- مجوزها:

  | مجوز | برای چه کاری | اختیاری؟ |
  |---|---|---|
  | `RECEIVE_SMS` | خواندن پیامک رمز | لازم برای عملکرد اصلی |
  | `SYSTEM_ALERT_WINDOW` | نمایش نوار شناور | لازم برای نوار |
  | `READ_SMS` | نمایش فهرست فرستنده‌ها برای انتخاب در لیست‌ها | اختیاری |
  | `VIBRATE` | لرزش | اختیاری |
  | دسترسی مدیریت اعلان‌ها | بستن اعلان پیامک | اختیاری |

## نصب

1. آخرین APK را از [Releases](https://github.com/asgtey/Ramzyar/releases) دانلود کنید.
2. نصب کنید (ممکن است نیاز به اجازهٔ نصب از منبع ناشناس باشد).
3. اپ را باز کنید و مجوز پیامک و نمایش روی برنامه‌ها را بدهید.

> نسخه‌های Release در CI با کلید موقت امضا می‌شوند (مگر کلید خودتان را تنظیم کنید)، بنابراین برای نصب نسخهٔ جدید ممکن است لازم باشد نسخهٔ قبلی را حذف کنید.

## ساخت از سورس

```bash
git clone https://github.com/asgtey/Ramzyar.git
cd Ramzyar

# تست‌های واحد پارسر رمز (روی JVM، بدون شبیه‌ساز)
./gradlew testDebugUnitTest

# ساخت نسخه دیباگ
./gradlew assembleDebug
```

نسخهٔ Release با [`.github/workflows/release.yml`](.github/workflows/release.yml) روی هر push به `master` ساخته و به‌صورت GitHub Release منتشر می‌شود. برای امضا با کلید خودتان این secretها را تنظیم کنید: `RELEASE_KEYSTORE_BASE64`، `RELEASE_STORE_PASSWORD`، `RELEASE_KEY_ALIAS`، `RELEASE_KEY_PASSWORD`.

**ابزارها:** Kotlin 2.0.21، AGP 8.13.2، Gradle 8.13، compileSdk 36، minSdk 24، JDK 17+.

## رفع اشکال

- **نوار ظاهر نمی‌شود** — مجوز Overlay را بررسی کنید و در ROMهای سخت‌گیر (MIUI، EMUI، ColorOS) بهینه‌سازی باتری را برای اپ خاموش کنید.
- **کد پیدا نمی‌شود یا عدد اشتباه است** — عبارت دقیق آن سرویس را به «کلمات کلیدی سفارشی» اضافه کنید؛ پارسر روی آخرین کلیدواژه لنگر می‌اندازد.
- **اعلان پیامک بسته نمی‌شود** — دسترسی «مدیریت اعلان‌ها» را بدهید؛ اندروید اجازهٔ تغییر وضعیت خوانده‌شده را فقط به اپ پیامک پیش‌فرض می‌دهد.
- **هیچ اتفاقی نمی‌افتد** — مطمئن شوید اپ دیگری (یا سرویس کد تأیید گوگل) مدیریت پیامک را در دست نگرفته است.
